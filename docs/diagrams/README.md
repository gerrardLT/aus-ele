## 使用说明

1. 每个文档包含绘制该图表所需的**全部结构化信息**
2. 可直接用于 draw.io / Mermaid / PlantUML / Excalidraw 等工具
3. 每个文档末尾有"图表建议格式"说明推荐的图表类型
4. 信息来源：`docs/项目技术架构与业务全景.md`

## 未包含的图表类型

以下图表类型在当前项目中暂不适用：

| 图表 | 原因 |
|------|------|
| 甘特图/项目计划 | 单人项目，无需多人排期 |
| 权限矩阵 | 当前无用户认证系统 |
