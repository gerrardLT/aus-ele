## 实现

### 新包 backend/agent/mcp/

1. **config.py**：McpServerConfig dataclass + 6 server 清单；三层启用判定（总开关 AUS_ELE_MCP_ENABLED → 单服务器 AUS_ELE_MCP_<KEY>_ENABLED → 必需 env 缺失自动 disabled）；URL 模板 {ENV} 占位符运行时注入（密钥不落配置文件）
2. **client.py**：McpGateway——stdio/http 懒启动连接（AsyncExitStack 生命周期）、工具列表缓存、30s 调用超时、健康状态机（连续 3 次失败 → degraded 短路 60s → 半开重试、成功即恢复）、结果解析（text→JSON→structured 三级提取）；mcp SDK 懒导入（无 SDK 环境可跑测试）
3. **adapter.py**：register_all_mcp_tools 动态发现注册进既有 ToolRegistry（工具名 mcp_<server>_<tool>，描述加「外部实时数据」前缀，async executor 包装）；结果统一包 {source, data_grade=official_live}；失败降级为 data_grade=unavailable + hint 观察值（LLM 可改走库内工具）；MCP_SERVER_TOOLS 供 profiles 并入

### 既有代码改动

4. **tool_profiles.py**：profile_tools 并入 mcp_tools_for_profile（懒导入防循环依赖）；确定性模板路径不含 MCP 工具（模板管线保持确定性），全量模式自动包含
5. **server.py lifespan**：startup 注册 MCP 工具（失败仅告警不阻断）+ shutdown 清理网关子进程
6. **requirements.txt**：+mcp>=1.2.0、uv>=0.4.0
7. **Dockerfile.backend**：uvx 构建期预热 5 个 stdio server 包（失败容忍）+ UV_CACHE_DIR
8. **docker-compose.prod.yml / ci.yml / deploy.sh**：透传 AUS_ELE_MCP_ENABLED + TAVILY_API_KEY（CI secret → .env.prod）；.env.docker.example 补文档占位

### 安全设计

- MCP 结果仅作数据观察包装进 ToolResult（prompt injection 防线：不执行返回内容中的指令）
- Tavily key 仅存环境变量/CI secrets，配置文件零明文
- 白名单 server（静态配置，不接受动态注册）
