# 市场事件案例卡片（2026-08 首版）

> 修改事件内容时以 JSON 为准并同步本文。维护节奏：事件驱动（发生即录），季度归档。

## 案例 1：SA 全州大停电｜black_system｜high
- 时间：2016-09-28，约 24 小时恢复
- 因果：风暴摧毁输电线路 → 黑系统 → 恢复期价格尖峰 + 行政定价触发
- BESS 影响：催生 SA 大规模电池部署；系统强度/黑启动价值进入视野
- 教训：极端事件收益尖峰不可作基线；事件后制度收紧会创造新价值流

## 案例 2：Liddell 煤电退役｜coal_retirement｜high
- 时间：2025-04 ~ 2025-06（约 2GW NSW 基荷分阶段退出）
- 因果：基荷缺口 → 峰时价格与波动抬升 → 尖峰依赖快速响应资源
- 教训：退役节点是价差突变的可预测驱动；退役前 1-2 年市场提前定价，进入时机看管线不看当前价差

## 案例 3：负价潮｜negative_price_wave｜high
- 时间：2025-10 ~ 2026-02（2025 Q4 负价占比 31% 创纪录，延续 2026）
- 因果：光伏大发 + 低需求 → 日内结构两极化（午间深负价 + 傍晚尖峰）
- BESS 影响：低成本充电窗口充裕，但整体价差收益被压缩
- 教训：负价比例是光伏蚕食深度的先行指标；收益越来越依赖"抓傍晚尖峰"

## 案例 4：FCAS 价格崩塌｜fcas_collapse｜high
- 时间：2024 ~ 2026（持续中）
- 因果：BESS 供给激增 → 供需比恶化 → 10/10 服务 collapsed；FCAS 占收入降至约 3%
- 系统护栏：压缩因子 0.3 + fcas_collapse_engine
- 教训：辅助服务容量有限；历史高收入不可外推

## 案例 5：NEM 储能收益连续创新低｜revenue_compression｜high
- 时间：2026-03 ~ 2026-05（Modo 指数 $44k → $29k/MW/年，均当时新低）
- 内部印证：benchmark NSW1 2026-03~06：59.96 → 50.03 kAUD/MW/年（同向）
- 因果：新增装机抢食收缩的 merchant 价值 →"量增价减"循环
- 教训：压缩周期里"项目 vs 基准"对照比绝对收益重要；CIS 对冲价值放大；进入决策看饱和度
