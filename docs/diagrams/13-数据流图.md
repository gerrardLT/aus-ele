## 数据同步频率

| 数据源 | 采集频率 | 数据粒度 | 延迟 |
|--------|----------|----------|------|
| AEMO NEM | 每日 1 次 | 5 分钟 | T+1 天 |
| AEMO WEM | 每日 1 次 | 30 分钟 | T+1 天 |
| WEM ESS | 每日 1 次 | 30 分钟 | T+1 天 |
| Fingrid | 增量同步 | 可变 | 近实时 |
| Nord Pool | 按需 | 小时 | 按需 |
| ENTSO-E | 按需 | 小时 | 按需 |
| 静态 JSON | 手动 | — | 季度/年度 |

## 数据转换规则

| 阶段 | 转换 | 说明 |
|------|------|------|
| 采集 → 存储 | 时区标准化 | NEM→AEST, WEM→AWST, Fingrid→EET |
| 采集 → 存储 | 缺失值处理 | 线性插值 / 标记为 NULL |
| 存储 → 引擎 | 时间范围过滤 | 按 start/end 查询 |
| 存储 → 引擎 | 区域过滤 | 按 region 筛选 |
| 引擎 → 缓存 | 序列化 | Python dict → JSON string |
| 引擎 → 前端 | 降采样 | LTTBC 算法（大数据集） |
| 引擎 → 前端 | 单位转换 | $/MWh, $/MW/年, % |
