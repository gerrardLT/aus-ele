# MCP Server fetch 启动报错修复

## 日期
2026-08-14

## 问题描述
Qoder IDE 启动时 MCP Server `fetch` 报错：
```
failed to initialize MCP client for fetch: transport error: context deadline exceeded
```

## 根本原因

`mcp-server-fetch` 2026.7.10 与 `mcp` Python SDK 2.0.0（2026-07-28 发布）版本不兼容。

具体链路：
1. MCP Python SDK v2 迁移中将异常类 `McpError` 重命名为 `MCPError`（参见 [v1→v2 迁移指南](https://py.sdk.modelcontextprotocol.io/migration/)）
2. `mcp-server-fetch` 2026.7.10 的 `server.py` 仍使用旧名称 `from mcp.shared.exceptions import McpError`
3. 其 `pyproject.toml` 声明 `mcp>=1.1.3` 无上限，uvx 不固定版本时会拉取到 2.0.0
4. 进程在 initialize 握手前即 `ImportError` 退出（exit code 1），客户端只能看到 `context deadline exceeded`

已知 issue：[modelcontextprotocol/servers#4560](https://github.com/modelcontextprotocol/servers/issues/4560)

## 解决方案

在 uvx 启动参数中通过 `--with "mcp<2"` 强制使用 mcp SDK 1.x：

**修改前**（`mcp.json` 中 fetch 的 args）：
```json
"args": ["mcp-server-fetch"]
```

**修改后**：
```json
"args": ["--with", "mcp<2", "mcp-server-fetch"]
```

配置文件路径：
`C:\Users\LT\AppData\Roaming\Qoder\SharedClientCache\extension\local\mcp.json`

## 验证结果

终端运行 `uvx --with "mcp<2" mcp-server-fetch` 并发送 initialize + tools/list 请求：

- initialize 握手成功，返回 `serverInfo: mcp-fetch 1.29.0`
- tools/list 成功，返回 `fetch` 工具定义
- 共安装 45 个包，耗时约 4 秒

## 注意事项

- 此为临时方案（上游 issue #4560 尚未关闭，PR #4577 待合并）。后续 `mcp-server-fetch` 发布修复版本后可移除 `--with "mcp<2"` 参数
- `mcp.json` 中 `userConfigMD5` 字段为旧值，如 IDE 检测到配置不一致而回退，需通过 IDE 设置界面（⌘⇧, / Ctrl+Shift+, → MCP）手动修改 fetch 参数
- 修改后需重启 Qoder IDE 或在 MCP 面板点击 Retry 重连
