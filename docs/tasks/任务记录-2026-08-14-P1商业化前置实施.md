## 实施内容

### P1-1 计量加固（agent_execution_log 按 workspace 归属）

1. `backend/routes/agent_routes.py`：`_AGENT_LOG_COLUMN_MIGRATIONS` 追加 workspace_id/principal_id 两列（复用既有独立连接+显式提交迁移模式）；`_log_execution` / `_log_execution_dict` 落库两列；三处调用点（/run、/run-async、/chat-stream）从 JWT claims（sub/workspace_id）传入身份；匿名 web-session 归入 ws_default

### P1-2 订阅与配额（支付后置）

1. `backend/database.py`：新表 `workspace_subscription`（workspace_id PK / plan / status / payment_provider / payment_ref 支付预留列 / started_at / updated_at）+ ensure/fetch/upsert 三方法
2. `backend/external_api_v1.py`：新增 `AGENT_RUN_DAILY_LIMITS`（starter 50 / growth 200 / pro 1000 / internal、enterprise 无限制）
3. `backend/routes/account_routes.py`：
   - `GET /workspaces/{ws}/subscription`：plan + 今日 Agent 运行/API units 用量与配额；软配额 over_quota 只标记不阻断；无记录默认 starter 不写库（避免并发建记录）
   - `POST /workspaces/{ws}/subscription`：仅 owner 切换套餐，payment_provider 记 manual（内部调套）
   - 进程内日计数缓存（workspace → (day, agent_runs, api_units)，60s TTL）避免每次聚合查库

## 过程中发现与修复

1. **substr(timestamptz) 类型错误**：PostgreSQL 无 `substr(timestamp with time zone, int, int)` 重载，按天聚合需 `created_at::text`——usage 两处聚合查询初版运行时报 UndefinedFunction（被 except 静默降级为空），已修
2. 配额缓存按 (day, counts) 键控，跨天自动失效；套餐切换后主动 pop 缓存
3. 定价/法务文案为内联组件不入 translations.js（篇幅大且低频）——上线前建议人工过目免责声明措辞
