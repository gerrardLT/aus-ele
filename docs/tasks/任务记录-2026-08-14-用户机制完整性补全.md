## 一、严重安全漏洞修复（无鉴权管理端点收紧）

核心机制：server.py 新增 `_require_bearer_actor` / `_resolve_admin_principal_id`——HTTP 调用一律用 Bearer 令牌内的 principal，旧端点的自报 principal_id/actor_principal_id 查询参数仅进程内直调可用（测试兼容），`Query(None)` 缺省对象按未提供处理（isinstance str 判定）。

| 端点 | 收紧方式 |
|---|---|
| POST /api/auth/password/set（任意重置密码漏洞） | Bearer 必需；仅本人或目标所在组织的 org_owner/org_admin |
| POST /api/admin/access-tokens（任意签发令牌漏洞） | Bearer 必需；仅本人（令牌主体==调用者） |
| POST /api/admin/organizations、POST /api/admin/principals | Bearer 必需（引导自举场景） |
| GET /api/admin/organizations | Bearer 必需；仅返回调用者所属组织（不再全量泄露） |
| POST .../organizations/{id}/members（原完全无鉴权） | Bearer + 组织内 member_manage 权限 |
| 组织成员列表/邀请 CRUD/撤销重发/停用恢复移除/批量/owner 转移/审计日志（11 个端点） | actor 取自令牌，不再信任自报参数 |
| OIDC provider/组织域名注册 | Bearer + 组织内 org_manage 权限 |

## 二、功能缺口实现（1-5）

### 1. 忘记密码
- 后端：POST /api/v1/account/password/reset-request（防邮箱枚举：统一响应；令牌 sha256 哈希存 password_reset 表，30 分钟 TTL，一次性）+ reset-confirm（重置后吊销该用户全部会话与令牌）
- 前端：LoginPage「忘记密码？」链接 → /forgot（请求邮件）与 /reset?token=（设新密码）复用 ForgotPasswordPage

### 2. 多工作空间切换
- access_control.switch_workspace_session（免密码，完整 workspace/组织资格校验，签发新会话+令牌，写审计 auth.workspace_switch）
- POST /api/v1/account/workspaces/{ws}/login-session；AuthContext.switchWorkspace；AccountPage 资料卡工作空间下拉（>1 个时显示）

### 3. 显示名编辑
- PATCH /api/v1/account/me；AccountPage 资料卡内联编辑

### 4. 会话管理
- GET /api/v1/account/sessions（活跃会话列表+当前标记）+ POST /sessions/revoke-others（保留当前，吊销其余会话与全部令牌）
- AccountPage「活跃会话」卡片 + 登出其他设备按钮

### 5. 管理员重置成员密码
- POST /api/v1/account/workspaces/{ws}/members/{pid}/reset-password（owner/admin；重置后目标全部会话失效）
- MembersPage 成员行内「重置密码」操作

## 过程中发现与修复

1. `Query(None)` 缺省值在进程内直调时是 Query 对象（truthy）导致误入鉴权分支并触发 psycopg2 "can't adapt type 'Query'"——改 isinstance str 判定修复
2. actor 的 session 可能为 None——`(actor.get("session") or {})` 防御
3. 重置邮件测试用 mock 发信，避免测试真实骚扰邮箱
