## 外部 API（后端 → 第三方）

| 目标 | 协议 | 认证 | 频率 | 超时 | 重试 |
|------|------|------|------|------|------|
| AEMO NEM API | HTTPS | 无 | 每日 | 30s | 3 次 |
| AEMO WEM API | HTTPS | 无 | 每日 | 30s | 3 次 |
| Fingrid API | HTTPS | API Key (Header) | 增量 | 30s | 3 次 |
| Nord Pool API | HTTPS | Bearer Token / Client Credentials | 按需 | 30s | — |
| ENTSO-E API | HTTPS | Security Token (Query) | 按需 | 30s | — |
