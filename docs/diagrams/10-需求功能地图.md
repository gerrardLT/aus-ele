## 按模块分组

### 分析模块（面向用户）

| 模块 | 输入 | 输出 | 核心算法 |
|------|------|------|----------|
| 价格趋势 | 区域+时间范围 | 折线图+统计 | LTTBC 降采样 |
| 区域排名 | 全部区域 | 排名表+雷达图 | 4 维度加权评分 |
| 极端价格 | 区域+阈值 | Spike 事件列表 | 阈值过滤+利润计算 |
| 饱和追踪 | 容量管道 JSON | 饱和度曲线 | 累计容量/需求比 |
| 容量稀释 | 基础收入+容量预测 | 稀释曲线 | 幂律 α=0.6 |
| FCAS 崩塌 | FCAS 供需数据 | 价格天花板曲线 | 供需比衰减 |
| 区域时机 | 多维度数据 | 评分卡 | 4 维度加权 |
| 商户风险 | 历史价格分布 | P10/P50/P90 | 蒙特卡洛重采样 |
| 前瞻价差 | 基础价差+压缩因子 | 20 年曲线 | 指数压缩+ML 校准 |
| 联合优化 | 价格+FCAS+电池参数 | 最优调度 | PuLP MILP |
| 财务建模 | 收入+成本+税务 | NPV/IRR/现金流 | numpy-financial |
| 收入分层 | 收入来源分解 | 3 层折现 | 独立折现率 |

### 数据管理模块（面向系统）

| 模块 | 频率 | 数据量 | 存储 |
|------|------|--------|------|
| NEM 价格同步 | 每日 | ~1440 行/天 (5 区域) | SQLite 按年分表 |
| WEM 价格同步 | 每日 | ~48 行/天 | SQLite 按年分表 |
| WEM ESS 同步 | 每日 | ~240 行/天 (5 类型) | SQLite 按年分表 |
| Fingrid 同步 | 增量 | 可变 | SQLite 按数据集 |
| 缓存管理 | 自动 | — | Redis 6h TTL |
