## 设计决策与备注

1. **通知中心用轮询不用 WebSocket**：未读数页面加载时查询，MVP 够用
2. **告警规则表不加订阅关系列**：既有 channel_type/channel_target 已是每规则渠道配置
3. **报告订阅=保存参数组合+手动生成**：定时邮件推送依赖邮件通道成熟度，留下一轮
4. **Onboarding 不用第三方库**：localStorage + CustomEvent，零依赖
5. 邮件降级链路保证告警不静默丢失：email 失败 → 站内通知 + delivery_log 记 degraded
