## 状态机 1：投资分析会话状态

```
[初始] ──→ 市场筛选中 ──→ 收入分析中 ──→ 饱和评估中
                                              │
                                              ▼
         投资决策 ←── 财务建模中 ←── 前景预测中 ←── 联合优化中
           │
     ┌─────┴─────┐
     ▼           ▼
  [Go 投资]   [No-Go 放弃]
```

| 状态 | 对应阶段 | 触发条件 | 可跳转 |
|------|----------|----------|--------|
| 市场筛选中 | Stage 1 | 用户进入 NEM/WEM 页面 | → 收入分析中 |
| 收入分析中 | Stage 2 | 用户选定区域 | → 饱和评估中 |
| 饱和评估中 | Stage 3 | 完成收入分析 | → 前景预测中 |
| 前景预测中 | Stage 4 | 完成饱和评估 | → 联合优化中 |
| 联合优化中 | Stage 5 | 完成前景预测 | → 财务建模中 |
| 财务建模中 | Stage 6 | 完成联合优化 | → 投资决策 |
| 投资决策 | Stage 7 | 完成财务建模 | → Go / No-Go |

**异常路径**：
- 任何阶段 → [中断] （用户离开）
- Stage 3 饱和度过高 → 直接 [No-Go]
- Stage 4 P90 收入不足 → 直接 [No-Go]

## 状态机 2：数据同步任务状态

```
[待调度] ──→ [运行中] ──→ [成功]
                │
                ├──→ [失败] ──→ [待重试] ──→ [运行中]
                │                    │
                │                    └──→ [永久失败] (重试 3 次后)
                │
                └──→ [超时] ──→ [待重试]
```

| 状态 | 触发条件 | 后续动作 |
|------|----------|----------|
| 待调度 | APScheduler 定时触发 | Worker 拾取执行 |
| 运行中 | Worker 开始执行 | 请求外部 API |
| 成功 | 数据写入 SQLite 完成 | 清除相关缓存 |
| 失败 | API 返回错误 / 解析异常 | 记录日志，进入重试 |
| 超时 | 请求超过 30s | 进入重试 |
| 待重试 | 失败/超时后 | 指数退避后重新执行 |
| 永久失败 | 重试 3 次仍失败 | 告警，人工介入 |

## 状态机 3：Redis 缓存条目生命周期

```
[不存在] ──→ [已缓存] ──→ [已过期]
                │              │
                │              └──→ [不存在] (TTL 到期自动删除)
                │
                └──→ [已失效] ──→ [不存在] (数据更新时主动清除)
```

| 状态 | TTL | 触发条件 |
|------|-----|----------|
| 不存在 | — | 首次请求 / TTL 过期 / 主动清除 |
| 已缓存 | 6h | 引擎计算完成后写入 |
| 已过期 | 0 | 6 小时后自动过期 |
| 已失效 | — | 数据同步后主动 DEL |

## 状态机 4：Fingrid 数据集状态

```
[planned] ──→ [configured] ──→ [live]
                    │
                    └──→ [error] ──→ [configured] (修复后)
```

| 状态 | 含义 | 条件 |
|------|------|------|
| planned | 已知数据集，未配置 API Key | 默认状态 |
| configured | API Key 已配置 | 环境变量设置 |
| live | 数据获取成功 | fetch 返回 200 |
| error | 获取失败 | fetch 返回错误 |

## 状态机 5：前端模块加载状态

```
[未注册] ──→ [已注册] ──→ [加载中] ──→ [已渲染]
                                │
                                └──→ [加载失败] ──→ [错误展示]
```

| 状态 | 触发 | UI 表现 |
|------|------|---------|
| 未注册 | marketConfig 中无此模块 | 不显示 |
| 已注册 | marketConfig 中已配置 | Tab 中可见 |
| 加载中 | React.lazy 开始加载 | 显示加载消息 |
| 已渲染 | 组件加载+数据获取完成 | 正常展示 |
| 加载失败 | 网络错误/组件错误 | 错误提示+重试按钮 |
