## 1. 调研结论总览（一句话版）

**对本项目（投资决策分析、深链查询为主、可审计硬约束）而言，"先进"不等于多代理或
全自主：最优组合是 单代理 ReAct 主干 + 确定性模板兜底 + 按阶段工具子集 + 意图路由 +
多层护栏（溯源/定界/熔断/诚实性），所有增强 flag 隔离、可一键回退。**

## 4. 意外发现清单（计划外收获）

1. **第二个 ReAct 死路径**：流式重试包裹 async 生成器导致主路径静默损坏（单测全绿测不出）；
2. **白名单 FROM 解析器被 EXTRACT(MONTH FROM col) 欺骗**误杀合法查询，且旧版未校验 JOIN 表（越权漏洞）；
3. **trading_price_2025 "缺失"是陈旧日志假象**——数据实际完整，基线结论需标时间窗；
4. **子集暴露的反幻觉作用**比省钱更珍贵（G07）；
5. **502 网关抖动频发**——熔断器从"建议项"变"必需品"，已上线。

## 5. ADR-001：工具子集暴露采用静态阶段子集 + 意图路由

- **结论**：采用"静态阶段子集（8 profile）+ 关键词意图路由 + 深度查询回落全量"，
  拒绝动态工具增删与 RAG 式工具检索。
- **理由**：(a) 动态增删破坏 KV-cache 前缀并引发悬空引用幻觉（Manus 实证反证）；
  (b) 本项目 31 工具规模下静态子集已省 70-92% schema 开销；(c) 意图路由误判的
  代价是完整性损失，故配两条安全网：无法归类回落全量、深度查询强制全量。
- **被否方案**：全量暴露（token 浪费 + 过度探索 + 幻觉面大）；RAG 工具检索
  （规模未到、复杂度不值）；按步动态掩码（logits 级控制在代理网关下不可用）。
- **失效条件**：工具数超 ~60 或出现强跨阶段查询模式时重审；供应商提供
  cache-aware 动态工具注入时重审。

## 6. ADR-002：单代理主干，多代理永不默认

- **结论**：维持单代理 ReAct + 模板兜底；多代理仅在"广度研究类"需求被真实流量
  证实后以独立模式评估。
- **理由**：本项目查询为深链证据链；Anthropic 的多代理收益场景（breadth-first）
  不匹配；token ~15x；Cognition 冲突假设原则；G06 显示单代理 + 正确工具集已足够。
- **失效条件**：出现稳定的多区域并行尽调类需求且单代理轨迹质量不足时重审。

## 7. ADR-003：护栏优先于能力

- **结论**：所有增强（子集/路由/plan-execute）默认关闭、flag 开启；护栏
  （溯源校验/定界/熔断/诚实性规则）默认开启、只观测不阻断。
- **理由**：投资决策场景错误成本不对称——省 token 的收益线性，编造数字的
  损失是信任崩塌；本项目两次"死路径"均因缺少运行时自检。
- **失效条件**：无（原则性决策）。
