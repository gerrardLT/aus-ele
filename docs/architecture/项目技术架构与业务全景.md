# AEMO Intelligence — 项目技术架构与业务全景

> 最后更新: 2025-05-27
> 目的: 让任何新接手的开发者在 15 分钟内建立全局认知

---

## 1. 项目概述

**产品名称**: AEMO Intelligence — 澳洲电网智能观测站

**一句话定位**: 面向储能投资分析师的 BESS 投资回报评估平台，覆盖价差套利 → FCAS 叠加 → 20 年现金流测算 → 投资决策全链路。

**目标用户**: 储能投资分析师、电力交易员、能源基金 PM

**核心价值**: 把原始市场数据翻译成可读的业务结论、收益边界和投资信号

**不是什么**: 不是自动交易系统、不是投资自动决策引擎、不是多市场联合最优调度系统

## 2. 业务领域与市场背景

### 2.1 支持的市场

| 市场 | 全称 | 区域 | 结算间隔 | 辅助服务 | 时区 |
|------|------|------|----------|----------|------|
| **NEM** | 国家电力市场 | NSW1, QLD1, VIC1, SA1, TAS1 | 5 分钟 | FCAS 10 种 | AEST |
| **WEM** | 西澳电力市场 | WEM | 30 分钟 | ESS 5 种 | AWST |
| **Finland** | 芬兰/北欧市场 | Fingrid 数据集 | 可变 | 储备价格 | EET |

### 2.2 市场关系

- NEM 和 WEM 是澳洲两个独立电力市场（东部 vs 西部）
- Finland/Nordic 是独立数据研究线，用于跨市场对比分析
- 三个市场共享同一套技术架构，通过 `market_adapter.py` 统一数据接口

### 2.3 BESS 投资的核心逻辑

电池储能（BESS）的收入来源：
1. **能量套利** — 低买高卖（峰谷价差）
2. **FCAS/ESS** — 提供频率调节辅助服务
3. **容量信用** — WEM 特有的容量市场收入

投资决策的核心问题：
- 哪个区域的价差最大？（市场筛选）
- 未来价差会被 BESS 饱和压缩多少？（前景分析）
- 20 年 NPV/IRR 是否达标？（财务建模）

## 3. 用户旅程（决策漏斗）

NEM 投资分析的 7 个阶段：

```
Stage 1: 市场筛选      → 哪个区域值得深入研究？
Stage 2: 收入深潜      → 这个区域历史上能赚多少？
Stage 3: 饱和与竞争    → 未来 BESS 容量增长会稀释多少收入？
Stage 4: 投资前景情景  → 20 年三情景（Central/High/Low）预测
Stage 5: 联合优化回测  → 历史最优调度策略验证
Stage 6: 财务建模      → NPV/IRR/税后现金流/融资结构
Stage 7: 投资决策      → 最终 Go/No-Go 结论
```

WEM 投资分析的 5 个阶段（Stage 4 和 6 合并）。

## 8. 核心算法与模型

### 8.1 MILP 调度优化

完美前瞻套利 + MPC 预测损耗代理：
```
Revenue_actual = Revenue_MILP × (1 - β_loss)    # β_loss = 15%
```

### 8.2 前瞻价格引擎（ForwardPriceEngine）

20 年三情景价差预测：
```
mean_spread = base_spread × Π(event_impacts) × compression_factor
compression = clamp(exp(-k × (r×s + w×f) / v), 0.05, 1.0)
```
- k=1.5（陡度）, w=1.5（PSF 权重）
- r = BESS 容量比, s = 情景敏感度, f = 价格设定频率, v = 区域波动性因子

### 8.3 容量稀释（CannibalizationEngine）

幂律模型：
```
revenue_per_mw = base_revenue / (capacity / base_capacity)^α    # α=0.6
```

### 8.4 FCAS 崩塌（FcasCollapseEngine）

供需比衰减模型：
```
price_ceiling = base_price × max(0, 1 - (supply_ratio - 1)^β)
```

### 8.5 商户风险（MerchantRiskEngine）

蒙特卡洛重采样（N×365 次）生成 P10/P50/P90 收入分布。

### 8.6 ML 校准（MLCalibrationEngine）

LightGBM Quantile Regression 从历史数据学习 base_spread：
- 训练: 2020-2023, 验证: 2024-2025
- 特征: lag_1_spread, lag_7_spread, rolling_7d_volatility, bess_capacity_ratio, 季节性
- 输出: P10/P50/P90 各区域 base_spread

### 8.7 非线性衰减模型

DoD 幂律：
```
等效折耗循环数 = DoD^α    # α=1.2
折损边际成本 = Capex_replacement / (Capacity × C_rated × η_rte) × α × DoD^(α-1)
```
