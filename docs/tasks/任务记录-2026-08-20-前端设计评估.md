## 4. 关键问题

### P1-1 `/api/api` 双前缀，异常监测功能失效
- 影响 Criteria：UX1、UX4、RB4
- 证据：浏览器控制台 5 个 404（`/api/api/v1/anomalies/NSW1`、`HEAD /api/api/peak-analysis` 等）；`AnomalyBadge.jsx#L31` 与 `MarketPage.jsx#L123` 对已含 `/api` 的 `marketConfig.js dataDependencies` 再拼 `API_BASE`。
- 后果：异常徽标永远无数据；空闲预取全部浪费。
- 修改建议：`dataDependencies` 去 `/api` 前缀或拼接前归一化。
- 预计回收：UX/RB 约 +1.5 分。

### P1-2 设计系统 SSOT 与实现双轨
- 影响 Criteria：VA4、TR4、PF4
- 证据：`DESIGN.md` 规定 Inter/Playfair、纯白安静权威、禁发光/玻璃拟态、max-width 1440；实现为 Archivo/Source Serif 4、dark-first、`glow-*`/`panel-glass`（backdrop blur）、max-width none。`index.html` 还预连接 Inter/Playfair 与 CSS 内 Archivo/Source Serif 重复，共 4 族字体。
- 修改建议：二选一对齐（建议把 DESIGN.md 更新为 dark-first 现状并修订反模式表），删除重复字体链。
- 预计回收：VA4/TR4/PF 约 +2 分。

### P1-3 首屏信息架构：筛选器吃掉第一视口
- 影响 Criteria：IA1、IA4、VA1、UX4
- 证据：新截图显示首屏 = 年份/区域/季度/日类型四大按钮组 + “收起筛选”全长 pill；价格图表在折叠线以下。
- 修改建议：筛选默认收起（保留一行摘要），图表/KPI 提入首屏。
- 预计回收：IA/VA 约 +2 分。

### P1-4 无障碍结构性缺口（gate 失败）
- 影响 Criteria：A11Y1、A11Y3、A11Y4
- 证据：`LoginPage.jsx` label 与 input 兄弟排列无 `htmlFor/id`；Tab 有 `role=tab/aria-selected` 但无 `tabpanel`、无方向键漫游；全局无 `aria-live/role=alert`；模态无 focus trap；<1100px 侧边栏隐藏且无替代导航。
- 修改建议：补 label 关联、tab 键盘模型、状态播报、移动端顶栏导航。

### P1-5 陈旧测试使质量信号失效
- 影响 Criteria：RB4、PF5
- 证据：`node --test src/lib/frontendStates.test.js` 等因 `src/App.jsx` 不存在 ENOENT 连败；`mainEntryPerformance.test.js` 断言与现 `main.jsx` 不符。
- 修改建议：重写或删除引用 App.jsx 的断言，恢复前端回归信号。

## 5. 视觉审美诊断

- Simplicity 2/4：局部组件语法统一，但首屏秩序弱、阶段间疏密两极（稀疏大数字 vs 极密面板）。
- Diversity 3/4：暗侧边栏 + 衬线编辑感数字 + 阶段徽章形成识别度；但卡片网格重复。
- Colorfulness 3/4：token 化语义色、双主题完整；emoji 与双轨 palette 破坏一致性。
- Craftsmanship 2/4：大量微决策来自同一系统，但 SSOT 双轨、陈旧快照、title=web 拉低“被认真管理”的观感。
- Complexity/Prototypicality 张力：分析工作台类别典型性保持良好（侧栏+Tab+KPI+图表），复杂度问题主要在首屏密度分配而非类别识别。
