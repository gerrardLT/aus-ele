一、了解项目全貌最核心的图
1. 项目全景图 / Context 图

回答：这个项目是什么、服务谁、和哪些外部系统有关？

适合放在 README 或项目介绍第一页。

内容包括：

用户是谁
系统边界在哪里
外部依赖有哪些
第三方服务有哪些
上下游系统有哪些

常见形式：

C4 Context Diagram
System Context Diagram
项目全景架构图

这是最重要的一张图。

2. 业务流程图

回答：业务是怎么跑起来的？

比如电商项目：

用户下单 → 支付 → 库存扣减 → 生成订单 → 发货 → 售后。

常见形式：

Flowchart
BPMN
用户旅程图
业务泳道图

如果项目涉及多人、多系统协作，推荐用泳道图，能看清楚每个角色负责什么。

3. 系统架构图

回答：系统由哪些模块组成？模块之间怎么通信？

内容包括：

前端
后端
网关
服务模块
数据库
缓存
消息队列
文件存储
第三方 API

常见形式：

C4 Container Diagram
微服务架构图
模块架构图
分层架构图

这是技术人员理解项目最常用的图。

4. 模块关系图 / 组件图

回答：每个系统内部有哪些核心模块？它们之间怎么依赖？

例如一个后端系统可能有：

用户模块
权限模块
订单模块
支付模块
通知模块
审计模块

常见形式：

Component Diagram
Module Dependency Diagram
Package Diagram

适合理解代码结构和模块边界。

5. 数据模型图 / ER 图

回答：项目的核心数据是什么？数据之间有什么关系？

内容包括：

表结构
实体关系
主外键
核心字段
数据生命周期

常见形式：

ERD
Data Model Diagram
Domain Model Diagram

如果是业务系统，ER 图非常关键。很多项目看懂数据库，基本就看懂了一半。

6. 时序图

回答：一次请求或一个关键场景内部到底发生了什么？

比如：

用户登录时：

前端 → API 网关 → 用户服务 → Redis → 数据库 → Token 服务 → 返回登录结果。

常见形式：

Sequence Diagram
API 调用链路图

适合解释：

登录
下单
支付
审批
消息推送
异步任务
第三方回调
7. 状态机图

回答：一个核心对象有哪些状态？状态之间如何流转？

比如订单状态：

待支付 → 已支付 → 待发货 → 已发货 → 已完成
或者：待支付 → 已取消。

常见形式：

State Machine Diagram
状态流转图

适合订单、工单、审批、任务、支付、合同、售后等场景。

8. 部署架构图

回答：系统实际部署在哪里？运行环境是什么？

内容包括：

服务器
Kubernetes
Docker
云服务
数据库实例
负载均衡
CDN
防火墙
VPC / 子网
多环境：dev、test、staging、prod

常见形式：

Deployment Diagram
Cloud Architecture Diagram
Network Topology Diagram

这个图是运维、DevOps、SRE、架构师最关心的。

二、除了技术图，现实项目中还需要这些图

很多人只画架构图，但现实中一个项目能不能成功，还要看管理、协作、成本、风险和交付。

9. 项目路线图 / Roadmap

回答：项目未来怎么演进？

内容包括：

当前版本
下一阶段
里程碑
关键功能
发布节奏
长期规划

适合给老板、客户、产品、团队同步方向。

10. 甘特图 / 项目计划图

回答：什么时候做什么？谁负责？什么时候交付？

内容包括：

任务拆分
时间线
依赖关系
负责人
截止日期
里程碑

适合项目经理和交付团队。

11. 需求地图 / 功能地图

回答：项目到底有哪些功能？功能之间怎么分层？

可以按模块组织：

用户端
管理端
运营端
支付中心
报表中心
权限中心

常见形式：

Feature Map
User Story Map
Mind Map
Product Map

这类图适合产品经理、业务方、开发团队对齐范围。

12. 用户旅程图

回答：用户从开始到完成目标经历了什么？痛点在哪里？

内容包括：

用户目标
操作步骤
情绪变化
触点
痛点
优化机会

适合 ToC、SaaS、平台型、服务型项目。

13. 权限矩阵图

回答：谁能看什么、做什么？

内容包括：

角色
菜单权限
数据权限
操作权限
审批权限

常见形式：

角色	查看订单	修改订单	退款	导出数据
管理员	✅	✅	✅	✅
客服	✅	❌	部分	❌
财务	✅	❌	✅	✅

现实项目中，权限矩阵经常比架构图还重要。

14. 接口关系图 / API Map

回答：系统之间通过哪些接口连接？

内容包括：

API 提供方
API 调用方
请求方向
同步/异步
鉴权方式
失败重试
限流策略

适合前后端协作、系统集成、微服务治理。

15. 数据流图

回答：数据从哪里来，到哪里去，中间怎么加工？

内容包括：

数据源
数据清洗
数据存储
数据同步
数据消费方
报表/BI
日志/埋点

常见形式：

DFD
Data Pipeline Diagram
ETL Flow
Event Flow

如果项目有数据分析、推荐、AI、BI，这张图很重要。

16. 安全架构图 / 威胁模型图

回答：系统有哪些安全边界和风险点？

内容包括：

认证
授权
数据加密
网络隔离
敏感数据
风险入口
攻击面
审计日志

常见形式：

Threat Model Diagram
Trust Boundary Diagram
安全分区图

金融、医疗、政企、支付、电商项目尤其需要。
