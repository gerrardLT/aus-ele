# 01 - 项目全景图 / System Context Diagram

> 回答：这个项目是什么、服务谁、和哪些外部系统有关？

---

## 系统名称

天枢 Tianshu — 澳洲电网智能观测站

## 系统定位

面向储能投资分析师的 BESS 投资回报评估平台，覆盖价差套利 → FCAS 叠加 → 20 年现金流测算 → 投资决策全链路。

## 用户角色

| 角色 | 说明 | 使用场景 |
|------|------|----------|
| 储能投资分析师 | 评估 BESS 项目投资回报 | 桌面端，单次 30-90 分钟深度分析 |
| 电力交易员 | 分析价差套利机会 | 日常市场监控 |
| 能源基金 PM | 投资组合决策 | 查看汇总结论和投资信号 |

## 系统边界

**天枢 Tianshu 平台**包含：
- Web 前端（React 19 + Recharts 可视化）
- API 后端（FastAPI + 25 个分析引擎）
- 后台 Worker（定时数据同步 + 任务队列）
- 数据存储（SQLite + Redis 缓存）

## 外部依赖 / 第三方服务

| 外部系统 | 类型 | 数据 | 接入方式 | 频率 |
|----------|------|------|----------|------|
| AEMO NEM | 数据源 | 5 分钟电价、FCAS 10 种 | HTTP API + CSV | 每日增量 |
| AEMO WEM | 数据源 | 30 分钟电价、ESS 5 种 | HTTP API + CSV | 每日增量 |
| Fingrid | 数据源 | 芬兰电网储备价格 | REST API (API Key) | 增量同步 |
| Nord Pool | 数据源 | 北欧日前市场价格 | REST API (Token) | 按需 |
| ENTSO-E | 数据源 | 欧洲电网数据 | REST API (Token) | 按需 |
| Modo Energy | 基准数据 | BESS 收入基准 | 手动 JSON | 季度 |
| AEMO ISP | 规划数据 | 煤电退役/BESS 管道 | 手动 JSON | 年度 |
| GitHub Actions | CI/CD | 自动测试+镜像推送 | Git Push 触发 | 每次提交 |
| GHCR | 镜像仓库 | Docker 镜像存储 | Docker Push | 主分支合并 |

## 上下游关系

```
上游（数据提供方）:
  AEMO → NEM/WEM 市场数据
  Fingrid → 芬兰储备价格
  Nord Pool → 北欧电价
  ENTSO-E → 欧洲电网
  Modo Energy → 行业基准

本系统:
  天枢 Tianshu 平台
  （采集 → 存储 → 计算 → 可视化 → 决策支持）

下游（数据消费方）:
  投资分析师 → 投资决策报告
  交易员 → 套利机会信号
  基金 PM → 投资组合调整
```
