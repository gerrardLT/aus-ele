## 整体分层

```
┌─────────────────────────────────────────────────────────────┐
│                    用户层 (Browser)                          │
│  React 19 + Vite 8 + Recharts + TailwindCSS + Framer Motion │
└─────────────────────────────┬───────────────────────────────┘
                              │ HTTP JSON API
┌─────────────────────────────▼───────────────────────────────┐
│                    网关层 (Nginx)                            │
│  静态文件服务 + 反向代理 /api → backend:8085                 │
└─────────────────────────────┬───────────────────────────────┘
                              │
┌─────────────────────────────▼───────────────────────────────┐
│                    API 层 (FastAPI :8085)                    │
│  19 个路由模块 → 参数验证 → 错误处理 → 响应契约             │
└───────┬─────────────────────┬───────────────────┬───────────┘
        │                     │                   │
┌───────▼───────┐  ┌──────────▼──────────┐  ┌────▼────┐
│  引擎层       │  │  缓存层             │  │ 依赖注入 │
│  25 个引擎    │  │  Redis (6h TTL)     │  │ deps.py  │
│  业务逻辑     │  │  cache_utils.py     │  └──────────┘
└───────┬───────┘  └─────────────────────┘
        │
┌───────▼───────────────────────────────────────────────────┐
│                    数据层                                   │

│  JSON 配置文件 (capacity/coal/financial_evidence)           │
└───────────────────────────────────────────────────────────┘
```

## 四个 Docker 服务

| 服务 | 镜像 | 端口 | 内存限制 | 职责 |
|------|------|------|----------|------|
| web | Nginx | 80 (外部 18080) | 384MB | 静态前端 + 反向代理 |
| backend | Python/FastAPI | 8085 (外部 18085) | 1200MB | API 服务 |
| worker | Python/FastAPI | 无外部端口 | 1536MB | 定时任务 + 作业队列 |
| redis | Redis 7 Alpine | 6379 (外部 16379) | 256MB | 缓存 + 任务队列 |

## 服务间通信

| 源 | 目标 | 协议 | 说明 |
|----|------|------|------|
| web (Nginx) | backend | HTTP | 反向代理 /api → backend:8085 |
| backend | redis | TCP | 响应缓存读写 (6h TTL) |
| worker | redis | TCP | 任务队列消费 |
| worker | SQLite | 文件 I/O | 数据同步写入 |
| backend | SQLite | 文件 I/O | 数据查询读取 |
| 前端 (Browser) | web (Nginx) | HTTPS | 静态资源 + API 请求 |
