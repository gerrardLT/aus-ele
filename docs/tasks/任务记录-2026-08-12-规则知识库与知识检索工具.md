## 目标

补齐常识/规则类问题的知识供给：从"LLM 参数知识裸答（不可溯源、有时效风险）"升级为"知识库确定性检索 + 来源引用"。

## 实施内容

1. **知识库** `data/knowledge/grid_rules.json`（schema_version=1）：
   - NEM 6 张卡片：5 分钟结算、IESS 注册规则、价格上下限与 MPC/CPT、FCAS 服务集与压缩现状、PFR 义务、Operating Reserve 改革（进行中）
   - WEM 3 张卡片：实时市场协同优化、RCM/BRCP 容量机制、ESS 5 服务集
   - 政策时间线 8 条（2021-05 ~ 2026-07）
   - 每张卡含四要素：source_url / effective_date / confidence / review_date；标注受影响价值流与系统模块

2. **检索服务** `backend/services/grid_knowledge.py`：
   - 确定性关键词检索（分词→title/summary/key_points 包含匹配→命中数排序），宁可少返回不做语义猜测
   - 支持 market / category 过滤；知识库缺失降级 available=False

3. **Agent 工具** `grid_knowledge_lookup`（Global - Knowledge 阶段）：
   - 参数：query / market / timeline（query 为空时自动附时间线）
   - profile 接入：stage1_screening / stage2_revenue / stage6_financial
   - 关键词路由：stage1_screening 新增"什么是/规则/机制/政策/制度/常识"
   - prompts 进度标签 + orchestrator 推理叙事（命中卡片 top3 摘要）

4. **人读版**：`docs/_references/电网规则知识卡片-2026-08.md`（JSON 为唯一真源，MD 供评审）

## 验证

- 新建 `tests/test_grid_knowledge.py` 10 用例：四要素完整性、id 唯一、中英检索命中、市场过滤、空命中、工具注册执行、profile 暴露——全绿
- 回归：assumptions_registry + benchmark_engine 合计 30/30；profile 一致性测试 5/5（72 subtests）
- 端到端："什么是 FCAS"命中 FCAS 卡片（含 source_url/effective_date/confidence）；WEM 浏览返回 3 卡 + 8 条时间线

## 已知边界

- confidence=medium 两条（PFR 义务细节、Operating Reserve）需优先复核
- 检索为包含式关键词匹配，同义词覆盖有限（如"现货价格上限"需命中"价格上下限"卡片依赖关键词）——后续可加 synonyms 字段
- 未做独立 API 端点（仅 Agent 工具消费），如需对外展示再补
