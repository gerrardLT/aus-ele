## 认证与授权

| 层面 | 当前状态 | 说明 |
|------|----------|------|
| 用户认证 | ❌ 无 | 当前为单用户/内部工具，无登录 |
| API 认证 | ❌ 无 | 所有 API 端点公开访问 |
| CORS | ✅ 限制 | 仅允许配置的 origins |
| 外部 API 认证 | ✅ 有 | Fingrid API Key, Nord Pool Token, ENTSO-E Token |

## 敏感数据

| 数据类型 | 存储位置 | 保护方式 |
|----------|----------|----------|
| Fingrid API Key | .env 文件 | .gitignore 排除 |
| Nord Pool Token | .env 文件 | .gitignore 排除 |
| ENTSO-E Token | .env 文件 | .gitignore 排除 |
| 市场价格数据 | SQLite | 文件系统权限 |
| Redis 缓存 | 内存 | Docker 网络隔离 |

## 风险点与攻击面

| 风险 | 严重度 | 当前缓解 | 建议 |
|------|--------|----------|------|
| API 无认证 | 中 | CORS 限制 + 内部使用 | 未来加 JWT |
| SQLite 文件暴露 | 低 | Docker 卷挂载 | 文件权限 600 |
| Redis 无密码 | 低 | Docker 内部网络 | 生产加密码 |
| .env 泄露 | 高 | .gitignore | 定期轮换 Key |
| 依赖漏洞 | 中 | GitHub Dependabot | 定期更新 |
| SSRF (外部 API) | 低 | 固定 URL 白名单 | — |
| 注入攻击 | 低 | Pydantic 验证 + 参数化查询 | — |

## 网络隔离

| 服务 | 可访问 | 不可访问 |
|------|--------|----------|
| web (Nginx) | 公网 :18080 | — |
| backend | 公网 :18085, Docker 内网 | — |
| worker | Docker 内网 | 公网（无端口映射） |
| redis | Docker 内网, 公网 :16379 (开发) | 生产应关闭外部端口 |
| SQLite | 文件系统（backend/worker 共享卷） | 网络不可达 |

## 数据加密

| 传输 | 加密 | 说明 |
|------|------|------|
| 浏览器 → Nginx | ❌ HTTP (开发) / ✅ HTTPS (生产) | 生产需配 TLS |
| Nginx → Backend | ❌ HTTP | Docker 内网，可接受 |
| Backend → Redis | ❌ 明文 | Docker 内网 |
| Backend → 外部 API | ✅ HTTPS | 所有外部请求走 HTTPS |
| SQLite 存储 | ❌ 明文 | 非敏感数据，可接受 |

## 审计日志

| 类型 | 当前状态 | 说明 |
|------|----------|------|
| API 访问日志 | ✅ 有 | FastAPI 标准日志 |
| 数据同步日志 | ✅ 有 | Worker 记录同步结果 |
| 错误日志 | ✅ 有 | 结构化 JSON 日志（可选） |
| 用户操作审计 | ❌ 无 | 无用户系统，暂不需要 |
| OpenTelemetry | ✅ 可选 | trace_id + span_id 关联 |
