## 目标

建立重大事件因果案例库，让归因叙事与"历史相似情景"推理从即兴描述升级为案例检索 + 来源引用。

## 实施内容

1. **案例库** `data/knowledge/market_events.json`（schema_version=1），首批 5 案例：

| id | 类别 | 时间 |
|---|---|---|
| sa_black_system_2016 | black_system | 2016-09-28 |
| liddell_retirement_2025 | coal_retirement | 2025-04~06 |
| negative_price_wave_2025q4 | negative_price_wave | 2025-10~2026-02 |
| fcas_collapse_2024_2026 | fcas_collapse | 2024~2026 |
| bess_revenue_record_lows_2026 | revenue_compression | 2026-03~05 |

每卡结构：summary / impact{price,fcas,bess} / duration / lessons[] / source_url / confidence / related_modules。其中收益新低案例与内部 benchmark 数据互为印证（NSW1 59.96→50.03 同向）。

2. **检索服务** `backend/services/market_events.py`：与 grid_knowledge 同模式（确定性关键词检索 + market/category 过滤 + 缺失降级）。

3. **Agent 工具** `market_event_lookup`（Global - Knowledge）：
   - profile 接入 stage2_revenue（收益异动归因）、stage4_outlook（崩塌/退役/负价情景）
   - 路由关键词：stage1_screening 新增"大停电/黑系统/煤电退役/历史上"
   - prompts 标签 + orchestrator 叙事（命中案例 top3：标题+时间+置信度）

4. **人读版** `docs/_references/市场事件案例卡片-2026-08.md`（JSON 唯一真源）。
