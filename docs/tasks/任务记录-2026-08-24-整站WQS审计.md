## 4. 关键问题

### P0-1 PricingPage 100% 白屏崩溃（主路径死路）
- **Severity**：P0（侧栏一级入口「定价与套餐」→ 白屏；商业转化死路）
- **影响**：WQS RB4/IA1/Gate2；用户看到的是彻底空白页，信任瞬间归零
- **证据**：控制台 `Cannot read properties of undefined (reading 'map')` + `An error occurred in the <PricingPage> component`；复现栈：编译后 PricingPage.jsx:223 `t.features.map`；源码 [PricingPage.jsx:104](../../web/src/pages/PricingPage.jsx#L104) 处 `t = zh ? plan.zh : plan.en` 而 `features` 定义在 `plan` 顶层（`plan.features.zh/en`）——**任何语言下必崩**；零测试覆盖（grep 全库无 PricingPage 测试）
- **修复**：`t.features.map` → `(plan.features[zh ? 'zh' : 'en']).map`（一行）；补最小渲染测试；全站加 ErrorBoundary
- **预计回收**：RB +1.0（RB4 1→3）、Gate2 解锁；约 **+1.5 分**

### P0-2 Stage 3/4 无限「加载中」（核心漏斗中断且静默）
- **Severity**：P0（本地实测 peak-analysis / fcas-analysis / hourly-price-profile 三接口 500 ×2 轮；UI 停留在 5 个堆叠的「加载中」，无错误提示、无重试入口、无降级）
- **影响**：Gate2；用户无法判断是慢还是坏，「竞争格局」「风险前瞻」两站对用户等于不存在
- **证据**：network 面板 500 ×6 + tabpanel 文本「加载中...」×5（切换 3 分钟后仍如此）
- **修复**：react-query 已有 isError 状态——渲染层补错误态卡片（「该模块数据暂时不可用 + 重试按钮」）；后端 500 根因另行排查（本地数据窗口）
- **预计回收**：RB1 1→3、UX1 2→3；约 **+1.6 分**

### P1-3 全站无 Error Boundary
- **Severity**：P1（任何组件崩溃 = 整页白屏，P0-1 即实证）
- **修复**：main.jsx 每个路由分支包 ErrorBoundary（React 官方模式），fallback 显示「页面出错 + 返回首页」
- **预计回收**：RB1/UX3 各 +0.5；约 **+0.7 分**

### P1-4 暗色主题主按钮白字对比 3.3:1
- **Severity**：P1（WCAG 2.2 AA 4.5:1 不达；dark primary=oklch(0.65 0.18 260) 上白字实测 3.3:1；主 CTA 高频）
- **证据**：OKLCH→sRGB 精确计算（workspace/tmp 临时脚本，正文/次要文本全部 AA 达标，仅此项与浅色 success 3.23 不达）
- **修复**：dark 主题按钮改用 `--color-inverted`（0.92L）底 + `--color-inverted-text` 深字，或将 primary 按钮文字提亮至 0.75L+；同轮修浅色 success 小字
- **预计回收**：A11Y2 3→4；约 **+0.6 分** + Gate3 前置条件

### P1-5 焦点指示新旧割裂（键盘可达性）
- **Severity**：P1
- **证据**：旧输入框（AssetConfigPanel/BessSimulator/AssumptionPanel/PeakAnalysis/FcasAnalysis 等约 15 处）`focus:outline-none + focus:border-xxx`——1px 边框变色为唯一焦点指示；新组件（Finland/Fingrid/PageWorkspaceNav）`focus-visible:ring-2 + offset + min-h-[44px]` 完整
- **修复**：index.css 加全局 `:focus-visible { outline: 2px solid var(--color-primary); outline-offset: 2px; }`，旧组件逐个迁到统一 ring 模式
- **预计回收**：A11Y3 2→3.5；约 **+0.9 分** + Gate6 前置条件

### P1-6 Finland 页开发契约语言直出
- **Severity**：P1（侧栏「其他市场 → Finland 市场」一级入口，进入后是工程交付状态页）
- **证据**：页面副标题「芬兰市场页已接入真实 board 契约。这层页面负责承接概览卡片、工作台切换和选择联动……」；「对应真实的 \`capacity_hourly\` 视图」（反引号直出）；「Overview 字段数 0 / Readiness 字段数 0」；主价格序列「暂无可选」
- **修复**：文案改为用户语言（「数据接入中，当前展示已就绪的容量价格模块」）；契约/字段数指标移入开发者门户；未就绪模块折叠或标注 Beta
- **预计回收**：IA1/PT4/TR4 各 +0.5；约 **+1.2 分**

### P1-7 内部枚举与方法名直出用户界面
- **Severity**：P1（Stage 1 市场现状大面积出现）
- **证据**：`BASELINE_POINT_FORECAST`、`window_probability_scan_v1`、`rolling_origin`、`SAMPLE POINTS`、`INFO VALUE`、`WEAKEST REGIME`、`STRUCTURAL_SUPPLY_OUTLOOK`（同卡片一处大写一处小写）、`research_and_operational_support_only`、`p2_forecast_layer`、`diagnostics unavailable`（英文描述整段未翻译）

## 5. 视觉审美诊断（VisAWI 四维视角）

- **Simplicity（3/4）**：布局分组、对齐、层级在截图与 DOM 上均清晰；Stage 1 信息密度偏高但结构可读——受控密度是金融工作台的合理选择。
- **Diversity（2/4）**：整站卡片语法高度同质（无尽 rounded-2xl 卡片），无 signature moment；唯一记忆点是天枢的信任组件群。漏斗 7 tab 视觉权重恒定，长滚动缺乏节奏变化。
- **Colorfulness（3.5/4）**：OKLCH 双主题 token 体系 + 打印主题，语义一致、状态色纪律严明（这是 Craftsmanship 的强项）；扣分在 primary 按钮对比与个别 accent 泛滥（分析预览橙色标签条）。
- **Craftsmanship（3/4）**：token 三套齐全、DESIGN.md 漂移治理有注释纪律；但新旧组件工艺断层明显（Finland ring-2+44px vs 旧输入框 1px border focus）、10-12px 字号系统偏小众、4px 滚动条。
- **Complexity/Prototypicality 张力**：类别典型性好——一眼可识别「专业金融数据工作台」（暗色+serif 标题+密集表格是 Bloomberg/Refinitiv 语系）；首屏复杂度对目标用户合理，对首次访客偏高（新手导览是正确的补偿机制）。

**Visual Intent Profile 现状推断**：Simplicity 5、Diversity 3、Colorfulness 4、Craftsmanship 5、Prototypicality 6.5、Complexity medium-high。若以 90 为目标：Diversity 需要定向补强（1-2 个 signature moment：如漏斗 stage 转场、决策建议页的结论卡片），而非全面改版。
