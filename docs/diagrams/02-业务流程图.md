## 核心业务流程：NEM BESS 投资分析（7 阶段决策漏斗）

```
Stage 1: 市场筛选
  输入: 全部 5 个 NEM 区域数据
  操作: 查看价格趋势、摘要统计、区域排名
  输出: 选定 1-2 个目标区域
  决策: 哪个区域值得深入研究？
    ↓
Stage 2: 收入深潜
  输入: 目标区域历史价格数据
  操作: 极端价格利润分析、峰谷价差统计
  输出: 历史收入水平（$/MW/年）
  决策: 这个区域历史上能赚多少？
    ↓
Stage 3: 饱和与竞争
  输入: BESS 容量管道数据 + 历史收入
  操作: 饱和追踪、容量增长趋势
  输出: 当前饱和度、未来容量预测
  决策: 未来 BESS 容量增长会稀释多少收入？
    ↓
Stage 4: 投资前景情景
  输入: 基础价差 + 压缩因子 + 事件影响
  操作: 20 年三情景预测（Central/High/Low）
  子模块:
    - 容量稀释模拟器（幂律模型）
    - FCAS 崩塌预测（供需比衰减）
    - 区域时机评分（4 维度）
    - 商户风险量化（蒙特卡洛 P10/P50/P90）
    - 前瞻价差曲线（含 ML 校准）
  输出: 20 年逐年价差预测 + 置信区间
  决策: 长期收入前景如何？
    ↓
Stage 5: 联合优化回测
  输入: 历史价格 + 电池参数 + FCAS 价格
  操作: MILP 联合优化（能量+FCAS）
  输出: 最优调度策略 + 实际可获收入
  决策: 历史最优策略能赚多少？
    ↓
Stage 6: 财务建模
  输入: 收入预测 + 成本结构 + 税务参数
  操作: NPV/IRR/税后现金流/融资结构计算
  子模块:
    - 收入风险分层（3 层独立折现）
    - 多源交叉验证
    - 事件标注叠加
    - 燃料敏感性分析
    - 网络增强影响
  输出: 20 年现金流表 + NPV + IRR + 回收期
  决策: 投资回报是否达标？
    ↓
Stage 7: 投资决策
  输入: 全部分析结果汇总
  操作: 综合评估 + 叙事归因
  输出: Go / No-Go 结论 + 投资备忘录
  决策: 最终投资还是放弃？
```

## WEM 投资分析流程（5 阶段，简化版）

```
Stage 1: 市场概览 → WEM 单区域价格+ESS 数据
Stage 2: 收入分析 → 能量套利 + ESS 收入 + 容量信用
Stage 3: 饱和分析 → WEM BESS 容量追踪
Stage 4+6: 前景+财务 → 合并为一步（WEM 市场较小）
Stage 5: 联合优化 → 能量+ESS 联合回测
```

## 关键分支与异常路径

| 分支点 | 条件 | 路径 |
|--------|------|------|
| Stage 1 结束 | 无区域达标 | 终止分析，报告"无投资机会" |
| Stage 3 结束 | 饱和度 > 80% | 标记高风险，仍可继续 |
| Stage 4 结束 | P90 收入 < 成本 | 建议放弃，可选继续 |
| Stage 6 结束 | IRR < 贴现率 | 结论 No-Go |

## 参与角色（泳道）

| 角色 | 参与阶段 | 职责 |
|------|----------|------|
| 分析师 | Stage 1-7 | 全流程操作 |
| 系统（自动） | Stage 1-6 | 数据采集、计算、缓存 |
| 基金 PM | Stage 7 | 最终决策审批 |
