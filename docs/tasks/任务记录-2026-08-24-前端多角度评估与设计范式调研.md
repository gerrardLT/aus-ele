## 四、多轮调研记录（5 轮）

### 轮 1：2026 宏观趋势（Figma / Muzli / Fuselab / Sanjay Dey）
- 有效趋势：**bento grid 布局、accessibility-first 设计系统、AI 个性化界面、预测式仪表板**（从静态报表转向预判用户需求）
- 应剔除的泡沫趋势：glassmorphism、neumorphism、3D 渐变——与本项目"可验证优先于装饰"定位冲突

### 轮 2：AI/Copilot 界面空间模式（uxdesign.cc / AG-UI / Smashing Magazine）
- **Smashing Magazine《Designing For Agentic AI》核心成果**——六大 UX 模式覆盖 agent 交互生命周期：
  - Pre-Action：Intent Preview（计划预览三选项：Proceed/Edit/Handle it Myself，接受率 >85%）、Autonomy Dial（四级渐进授权）
  - In-Action：Explainable Rationale（"因为你说过 X，所以我做了 Y"）、Confidence Signal（防自动化偏见，校准分 >0.8）
  - Post-Action：Action Audit & Undo（撤销率 <5% 为健康）、Escalation Pathway（升级频率 5–15%）
- 关键论断："Autonomy is an output of a technical system; trustworthiness is an output of a design process"

### 轮 3：Google Stitch / DESIGN.md 官方规范（google-labs-code/design.md）
- 格式 = YAML frontmatter tokens + 有序 `##` 章节（Overview→Colors→Typography→Layout→Elevation & Depth→Shapes→Components→Do's and Don'ts；未知扩展章节保留不报错）
- 官方 CLI：`npx -p @google/design.md designmd lint|diff|export`（Windows 必须用 `designmd` 别名避开 .md 文件关联）
- export 支持 json-tailwind / css-tailwind / dtcg 三格式——可作为 token 双源合一的解决路径
- lint 规则：broken-ref（error）、contrast-ratio（WCAG AA 4.5:1）、orphaned-tokens 等 11 条

### 轮 4：经典理论 + 标杆产品（NN/g / Tufte / Linear / Bloomberg）
- **NN/g preattentive processing**：定量信息只用 **长度与 2D 位置**编码；颜色只表达分类不表达量级；禁 pie/donut/gauge/treemap/3D；单一强调色使关键信息定位快 39%
- **Tufte**：data-ink 最大化、small multiples 优于单张超载图；深意不是删减而是"腾出墨水给更多数据层"
- **Linear**：近黑画布 + 发丝线 + 受控 glow 是 dark-first 工具类标杆；bento + 模糊光斑属营销页手法，工具内部应克制
- **Bloomberg**："conceal complexity"——复杂度不消除而是渐进隐藏，专家密度与新手可进入性并存
- **书籍**：《Refactoring UI》（层级靠字号字重而非颜色数量、预设 scale 等级）、《The Visual Display of Quantitative Information》（Tufte）、NN/g Application Design 课程框架

### 轮 5：暗色主题工程化（Material Design / muz.li）
- Material 暗色主题：tonal elevation（用表面亮度阶代替阴影）、深色面对 100% 白文字建议 ≥15.8:1 基底对比、状态层用 overlay 而非改色
- 本项目三级表面阶（0.13→0.16→0.19）与该范式一致，v2 明确写入规范依据
