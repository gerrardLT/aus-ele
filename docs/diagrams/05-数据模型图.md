# 05 - 数据模型图 / Data Model Diagram

> 回答：项目的核心数据是什么？数据之间有什么关系？

---

## 数据库：SQLite (aemo_data.db ~2GB)

### 核心表结构

#### NEM 价格表（按年分表）

```
表名: trading_price_{year}  (如 trading_price_2020, trading_price_2021, ...)

字段:
  - timestamp       DATETIME    主键（5 分钟间隔）
  - region          TEXT        区域 (NSW1/QLD1/VIC1/SA1/TAS1)
  - price           REAL        结算价格 ($/MWh)
  - demand          REAL        区域需求 (MW)（可选）
```

#### WEM 价格表（按年分表）

```
表名: wem_trading_price_{year}

字段:
  - timestamp       DATETIME    主键（30 分钟间隔）
  - region          TEXT        区域 (WEM)
  - price           REAL        结算价格 ($/MWh)
```

#### WEM ESS 辅助服务表（按年分表）

```
表名: wem_ess_{year}

字段:
  - timestamp       DATETIME    主键
  - service_type    TEXT        服务类型 (5 种 ESS)
  - price           REAL        服务价格
  - volume          REAL        服务量
```

#### Fingrid 数据集表

```
表名: fingrid_{dataset_id}  (如 fingrid_317)

字段:
  - timestamp       DATETIME    主键
  - value           REAL        数据值
  - dataset_id      INTEGER     数据集 ID
```

### 表关系

```
trading_price_{year} ──┐
                       ├── 通过 region + timestamp 关联
wem_trading_price_{year} ──┤
                       │
wem_ess_{year} ────────┘── 通过 timestamp 关联 WEM 价格

fingrid_{dataset_id} ──── 独立表，通过 dataset_id 区分
```

## 数据生命周期

```
1. 采集 (Scrapers)
   AEMO API → 原始 CSV/JSON → 解析清洗
     ↓
2. 存储 (SQLite)
   按年分表写入 → 索引 (timestamp, region)
     ↓
3. 查询 (database.py)
   引擎按时间范围+区域查询 → 返回 DataFrame/列表
     ↓
4. 计算 (Engines)
   统计分析 / MILP 优化 / ML 预测
     ↓
5. 缓存 (Redis)
   计算结果缓存 6 小时 TTL
     ↓
6. 展示 (Frontend)
   JSON API → Recharts 图表
```

## 数据量估算

| 数据类型 | 记录数/年 | 总量 |
|----------|-----------|------|
| NEM 5min 价格 | 5 区域 × 105,120 = 525,600 | ~6 年 = 315 万行 |
| WEM 30min 价格 | 1 区域 × 17,520 | ~6 年 = 10.5 万行 |
| WEM ESS | 5 类型 × 17,520 = 87,600 | ~6 年 = 52.5 万行 |
| Fingrid | 可变 | 多数据集 |
