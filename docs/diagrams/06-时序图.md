## 场景 1：用户查看价格趋势（缓存命中）

```
用户(Browser)    Nginx(web)    FastAPI(backend)    Redis    SQLite
    │                │               │               │         │
    │─── GET /api/price-trend?region=NSW1&year=2024 ──────────→│
    │                │               │               │         │
    │                │←── 反向代理 ──→│               │         │
    │                │               │               │         │
    │                │               │── 查缓存 ────→│         │
    │                │               │←── 命中 ──────│         │
    │                │               │               │         │
    │←────────── JSON 响应 (含 metadata) ────────────│         │
    │                │               │               │         │
```
