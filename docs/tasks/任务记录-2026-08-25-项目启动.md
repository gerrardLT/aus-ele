## 启动方式

沿用既有本地开发流程（同 2026-08-24 整站 WQS 审计的 running 阶段配置）：

1. **后端**（后台进程，日志 `workspace/logs/backend-live.out.log`）：

   ```powershell
   cd g:\project\aus-ele\backend
   g:\project\aus-ele\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8085
   ```

   - `server.py` 启动时自动加载根目录 `.env`（`os.environ.setdefault`），连接本地 PostgreSQL `localhost:5432/aemo_data`
   - PostgreSQL 本体位于 `G:\PostgreSQL\`，进程常驻，监听 `127.0.0.1:5432`（`Get-NetTCPConnection` 按端口过滤会漏报，需用 `netstat -ano` 确认）

2. **前端**（后台进程，日志 `workspace/logs/web-live.out.log`）：

   ```powershell
   cd g:\project\aus-ele\web
   npm run dev
   ```

   - Vite 绑定 `localhost:5173`（本机解析为 IPv6，`127.0.0.1:5173` 可能不通，访问用 `http://localhost:5173`）
