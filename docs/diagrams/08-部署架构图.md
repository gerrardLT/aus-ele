## Docker Compose 部署拓扑

```
┌─────────────────────────────────────────────────────────────────────┐
│                        宿主机 (Linux/Windows)                        │
│                                                                      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌─────────┐ │
│  │   web        │  │  backend     │  │   worker     │  │  redis  │ │
│  │  Nginx       │  │  FastAPI     │  │  FastAPI     │  │  7-alp  │ │
│  │  :80         │  │  :8085       │  │  (无端口)    │  │  :6379  │ │
│  │  384MB       │  │  1200MB      │  │  1536MB      │  │  256MB  │ │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘  └────┬────┘ │
│         │                  │                  │               │      │
│  ───────┴──────────────────┴──────────────────┴───────────────┘      │
│                        Docker 内部网络                                │
│                                                                      │
│  端口映射:                                                           │
│    宿主 18080 → web:80                                               │
│    宿主 18085 → backend:8085                                         │
│    宿主 16379 → redis:6379                                           │
│                                                                      │
│  数据卷:                                                             │
│    ./data      → /app/data       (SQLite 数据库)                     │
│    ./output    → /app/output     (输出文件)                          │
│    ./data_lake → /app/data_lake  (数据湖)                            │
│    ./logs      → /app/logs       (日志)                              │
│    redis_data  → /data           (Redis AOF 持久化)                  │
└─────────────────────────────────────────────────────────────────────┘
```

## 服务详情

### web 服务

| 属性 | 值 |
|------|-----|
| 基础镜像 | Nginx (自定义 Dockerfile) |
| 构建参数 | VITE_API_BASE, NPM_REGISTRY |
| 内存限制 | 384MB |
| 外部端口 | 18080 |
| 依赖 | backend |
| 职责 | 静态前端文件服务 + 反向代理 /api → backend |

### backend 服务

| 属性 | 值 |
|------|-----|
| 基础镜像 | Python 3.11 (Dockerfile.backend) |
| 内存限制 | 1200MB |
| 外部端口 | 18085 |
| 依赖 | redis |
| 环境变量 | AUS_ELE_DB_PATH, REDIS_URL, CORS, Fingrid 配置 |
| 调度器 | 默认关闭 (ENABLE_SCHEDULER=false) |
| Job Worker | 默认关闭 (ENABLE_JOB_WORKER=false) |

### worker 服务

| 属性 | 值 |
|------|-----|
| 基础镜像 | 同 backend (Dockerfile.backend) |
| 内存限制 | 1536MB |
| 外部端口 | 无 |
| 依赖 | redis |
| 调度器 | 默认开启 (ENABLE_SCHEDULER=true) |
| Job Worker | 默认开启 (ENABLE_JOB_WORKER=true) |
| 职责 | 定时数据同步 + 异步任务处理 |

### redis 服务

| 属性 | 值 |
|------|-----|
| 镜像 | redis:7-alpine |
| 内存限制 | 256MB |
| 外部端口 | 16379 |
| 持久化 | AOF (appendonly yes) |
| 数据卷 | redis_data:/data |

## CI/CD 流水线

```
开发者 Push/PR
    ↓
GitHub Actions 触发
    ↓
┌─────────────────────────────────────────┐
│ Job: backend (并行)                      │
│   - Python 3.11 setup                   │
│   - pip install                         │
│   - mypy 类型检查                       │
│   - unittest 单元测试                   │
│   - unittest 集成测试                   │
└─────────────────────────────────────────┘
┌─────────────────────────────────────────┐
│ Job: frontend (并行)                     │
│   - Node 20 setup                       │
│   - npm ci                              │
│   - ESLint                              │
│   - 前端测试                            │
│   - Vite build                          │
└─────────────────────────────────────────┘
    ↓ (两个 Job 都通过)
┌─────────────────────────────────────────┐
│ Job: docker (仅 main 分支 push)          │
│   - 登录 GHCR                           │
│   - Build backend 镜像                  │
│   - Build web 镜像                      │
│   - Push 到 ghcr.io                     │
│   - 标签: latest + commit SHA           │
└─────────────────────────────────────────┘
```

## 环境配置

| 环境 | 说明 | 特点 |
|------|------|------|
| 本地开发 | 直接运行 uvicorn + vite dev | 无 Docker，端口 8085+5173 |
| Docker 本地 | docker-compose up | 4 服务，端口 18080+18085 |
| 生产 | Docker Compose + 外部 Nginx | 同 Docker 本地，可加 HTTPS |
