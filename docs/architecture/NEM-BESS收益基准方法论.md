# NEM BESS 收益基准方法论（bess_benchmark_v1）

更新时间：2026-08-13

适用范围：
- `backend/engines/benchmark_engine.py`（实现）
- `GET /api/benchmark/nem-bess-index`、`/api/benchmark/nem-bess-region-compare`（API）
- Agent 工具 `bess_revenue_benchmark`（对话入口）

本文是 NEM BESS 收益基准指数的**正式方法论**（知识库规划 §2.4），对标 Modo ME BESS AUS NEM Index 公开方法论的规格。任何口径变更必须同步本文并升级 `methodology_version`。

## 1. 定位与用途

| 项 | 说明 |
|---|---|
| 回答的问题 | "一个参考储能资产在某区域的市场收益能力是多少、趋势如何" |
| 用途 | 市场进入判断的收益锚定、投资测算的市场对照、收益异动归因 |
| 数据等级 | `derived`（派生口径，非观测收入） |
| 明确禁止 | 与 Modo/Aurora 等第三方指数的**绝对值**直接对比（只比方向与量级） |

## 2. 参考资产定义

| 参数 | 取值 | 来源 |
|---|---|---|
| 功率 | 100 MW | 假设登记库 `benchmark_reference_battery`（wired） |
| 容量 | 200 MWh（2h） | 同上 |
| 往返效率 RTE | 0.85 | 同上 |
| 运行假设 | 理想算子：完美 foresight，无投标摩擦、无竞争、无停运 | 本方法论 §3 |

参考资产量级与 Modo 指数参考资产一致（2h 电网级储能），保证量纲可比。

## 3. 计算口径（理想日内循环套利）

对窗口内每个自然日独立计算：

1. 将该日全部结算价排序；
2. **放电**：取最高价 `cycle_intervals` 个时段，`cycle_intervals = round(电池时长 / 时段长度)`（2h 电池在 5 分钟粒度下 = 24 个时段）；
3. **充电**：取最低价 `cycle_intervals` 个时段；
4. 日放电能量 = min(时段数 × 功率 × 时段长度, 电池容量)；充电能量 = 放电能量 / RTE；
5. 日净收入 = 放电能量 × 放电均价 − 充电能量 × 充电均价；
6. **非负钳制**：净收入为负的日视为不循环（理想算子不亏损运行），计 0；
7. 月度净收入 = 当月各日之和。

**年化指数**：`index = 月度净收入 / 功率 × 12 / 1000`，单位 `kAUD/MW/年`。

口径特征：
- 每日一次满充放（不做多循环/跨日优化——对 2h 电池等价性差异很小，换来算法透明可复现）；
- 不含 FCAS / 容量 / CIS / 任何合约收入（`coverage_mode: arbitrage-only, FCAS not included`）；
- 不含网络费、市场费、退化成本。

## 4. 数据源与粒度

| 项 | 说明 |
|---|---|
| 数据源 | AEMO 结算价（`trading_price_<year>` 分年表，region_id + rrp_aud_mwh） |
| 粒度 | **从数据推断**：`interval_hours = 24 / 日均数据点数`（库内可达 5 分钟粒度）；循环时段数与完整性分母随粒度联动 |
| 窗口 | 滚动 `months` 个完整自然月（默认 12），**当前未完结月永远排除** |
| 完整性 | 月度完整性 = 实际点数 / 期望点数；≥95% 视为完整月；latest 与区域对比只取完整月；<90% 打 `incomplete_month` 告警；无数据月打 `no_data` |
| 容错 | 跨年表自动拼接；缺失年表跳过并由完整性告警兜底，不抛裸 SQL 错误 |

## 5. 覆盖边界（必须随输出暴露）

输出强制携带：`coverage_mode`、`caveats`、`metadata.data_grade=derived`、完整性字段。caveat 固定四条：

1. 理想日内循环套利口径（完美 foresight，无竞争/摩擦）
2. 不含 FCAS / 容量 / CIS 等其他价值流
3. 不含网络费与市场费
4. derived 口径，禁止与第三方指数绝对值直接对比

## 6. 已知偏差与第三方校准记录

**偏差来源分析**（我们 vs 第三方实际收益指数）：

| 方向 | 因素 | 说明 |
|---|---|---|
| 偏高 | 理想算子 | 完美 foresight + 无竞争压价 + 无停运，实际资产做不到 |
| 偏低 | 只含套利 | 第三方实际收益含 FCAS/合约等残余价值流 |
| 中性 | 参考资产同量级 | 2h 电池口径一致 |
